# 3.1
For version control and collaboration, GitHub was used extensively; each team member was assigned a dedicated feature branch to develop specific components (e.g., cart functionality, API integration). Once features were completed, these branches were merged into the main branch following code reviews, ensuring smooth integration and minimizing conflicts. GitHub Actions also supported continuous integration, running automated tests on pull requests to maintain code quality.

Flask enables efficient handling of routing, session management, data storage, and third-party API integrations.
The backend manages data requests and responses, authentication, session control, and the integration of APIs, specifically the Kroger API for product data and the SendGrid API for email notifications.
